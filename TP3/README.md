# TP3 - Configuration des cibles et gestion des services par Systemd

## Objectifs
- Comprendre le fonctionnement de Systemd.
- Configurer les cibles Systemd.
- Gérer les services avec systemctl.
- Consulter les journaux avec journalctl.
- Créer un service personnalisé.

## Ateliers
- Atelier 1 : Bases de Systemd et systemctl.
- Atelier 2 : Configuration des cibles Systemd.
- Atelier 3 : Gestion des services.
- Atelier 4 : Journalisation avec journalctl.
- Atelier supplémentaire : Création d'un service personnalisé.

## Environnement
- Red Hat Enterprise Linux 9
- VMware

## Conclusion
Ce TP a permis de découvrir Systemd, de gérer les services Linux, de configurer les cibles et de consulter les journaux système.

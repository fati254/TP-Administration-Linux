TP2 - CONFIGURATION GRUB2
=========================

PARTIE 1 : DECOUVERTE DE GRUB2

1. Identifier le mode de démarrage :
[ -d /sys/firmware/efi ] && echo "Mode UEFI" || echo "Mode BIOS (Legacy)"

2. Explorer le répertoire /boot :
ls -l /boot

3. Explorer les fichiers GRUB :
ls -l /boot/grub2

4. Afficher le noyau actuellement utilisé :
uname -r

5. Lister les noyaux installés :
rpm -q kernel-core


PARTIE 2 : CONFIGURATION GRUB2

1. Consulter les paramètres :
cat /etc/default/grub

2. Lister les scripts GRUB :
ls -l /etc/grub.d/


PARTIE 3 : MODIFICATION DE LA CONFIGURATION

1. Sauvegarder les fichiers :
cp -p /etc/default/grub /root/grub.default.bak
cp -p /etc/grub.d/40_custom /root/40_custom.bak
cp -p /boot/grub2/grub.cfg /root/grub.cfg.bak

2. Modifier les paramètres dans /etc/default/grub :
GRUB_TIMEOUT=10
GRUB_TIMEOUT_STYLE=menu
GRUB_DEFAULT=1

3. Ajouter les entrées personnalisées dans /etc/grub.d/40_custom.

4. Régénérer la configuration :
grub2-mkconfig -o /boot/grub2/grub.cfg


PARTIE 4 : REINITIALISATION DU MOT DE PASSE ROOT

Partie non réalisée.


PARTIE 5 : PROTECTION DE GRUB PAR MOT DE PASSE

1. Créer un mot de passe GRUB :
grub2-setpassword

2. Régénérer la configuration :
grub2-mkconfig -o /boot/grub2/grub.cfg

3. Vérifier l'existence du fichier :
ls -l /boot/grub2/user.cfg

IMPORTANT :
Ne jamais copier le contenu de /boot/grub2/user.cfg dans ce dépôt GitHub.
